# Таймлайн «Текст как данные»

Интерактивная шкала ключевых работ о тексте как данных — от подсчёта букв
у Маркова (1913) до языковых моделей в роли разметчиков (2023). Собрана
на [TimelineJS3](https://timeline.knightlab.com/) (Knight Lab), данные лежат
в одном JSON-файле, страница публикуется на GitHub Pages.

Источник содержания — два документа: [`Timeline.md`](Timeline.md) и
[«Дополнения к таймлайну теория и критика до 2000-х.md»](Дополнения%20к%20таймлайну%20теория%20и%20критика%20до%202000-х.md).
Всего 53 события на трёх дорожках, ссылки по ГОСТ Р 7.0.5-2008.

| Дорожка | Главных | Дополнительных | До 2000 | После 2000 |
| --- | --- | --- | --- | --- |
| Методы | 10 | 12 | 9 | 13 |
| Теория | 14 | 1 | 6 | 9 |
| Критика | 15 | 1 | 6 | 10 |

## Как устроены данные

### Дорожки

Поле `group` у события: `Методы`, `Теория`, `Критика`. TimelineJS рисует каждую
группу отдельным рядом на ленте.

Порядок рядов задать нельзя: библиотека сортирует события по дате и нумерует
группы по первому появлению. Поэтому ряды идут **Методы (1887) → Критика (1916)
→ Теория (1954)**, а не «методы — теория — критика».

### Эпохи

Четыре записи в `eras`, у каждой обязательны `start_date` и `end_date`.
Цвета заданы в `assets/custom.css` переменными `--era-1 … --era-4`.

Важно: TimelineJS раздаёт эпохам классы по кругу `color1 → color2 → … → color5
→ color0`, то есть **первая эпоха получает `tl-timeera-color1`**, а не `color0`.
Номера переменных в CSS подогнаны под это, и те же цвета стоят у кружков
в легенде — при добавлении эпохи проверьте, что оба места сходятся.

### Адреса карточек и пары «метод — критика»

Стрелок между карточками TimelineJS не рисует. Вместо них — ссылки внутри
описаний. Работает это так:

1. У каждого события есть `unique_id`, в опциях включён `hash_bookmark: true`.
   Адрес карточки — `#event-<unique_id>`, например
   `.../#event-markov-1916`. Этим адресом можно делиться.
2. Библиотека слушает `hashchange`, поэтому обычная ссылка
   `<a href='#event-markov-1916'>` переводит шкалу на нужную карточку.
3. **`target='_self'` обязателен.** TimelineJS прогоняет HTML карточек через
   DOMPurify и вешает `target="_blank"` на каждую ссылку, у которой атрибута
   `target` нет. Без `_self` переход по паре открывает новую вкладку.
   Внешние ссылки (DOI, URL) оставлены с `target='_blank'` намеренно.

`unique_id` должен состоять из латиницы, цифр и дефисов и начинаться с буквы:
библиотека пропускает идентификаторы через slugify, который вырезает кириллицу
и подставляет `_` перед начальной цифрой. Схема здесь — `фамилия-год`
(`markov-1916`, `grimmer-roberts-stewart-2022`).

### Соразмерность событий

Размер маркера TimelineJS не различает, поэтому масштаб передан текстом:

* **главные работы** — картинка, абзац описания, ссылка по ГОСТ, блок переходов;
* **дополнительные события** — одна строка в `<p class='tl-minor'>` и ссылка,
  без картинки.

Классы абзацев внутри карточек:

| Класс | Что это |
| --- | --- |
| `tl-lede` | лид титульной карточки |
| `tl-line` | подзаголовок-«линия»: гуманитарная, социально-научная, русская ветка |
| `tl-ref` | ссылка по ГОСТ |
| `tl-link` | блок переходов к парным карточкам |
| `tl-minor` | одна строка у дополнительного события |
| `tl-verify` | что осталось сверить вручную |

У всех событий стоит `"autolink": false`: ссылки расставлены руками, а автолинковщик
библиотеки оборачивает в `<a>` в том числе и видимый текст URL, ломая разметку.

### Картинки

Поля `media.url`, `media.caption`, `media.credit`. Сейчас картинки есть
у трёх карточек (Марков, Морозов, Лассуэлл) — файлы с Wikimedia Commons,
лицензия указана в `credit`. Чтобы добавить картинку, достаточно дописать блок
`media` в событие; на дополнительных событиях картинок нет сознательно.

### Что объединено и перенесено

Второй документ предлагал три перестановки, чтобы разгрузить 2010-е; они сделаны:

* **Джокерс 2013** переведён в формат дополнительного события (одна строка),
  а макроанализ упомянут фразой в карточке Моретти.
* **Гриммер, Робертс, Стюарт 2022** больше не отдельное событие: книга описана
  абзацем и второй ссылкой в карточке их же статьи 2013 года.
* **Бендер и Коллер 2020** и **Бендер и др. 2021** слиты в одно событие
  `bender-2020-2021` с `end_date`, то есть маркером-отрезком на ленте.

Старых адресов `#event-grimmer-roberts-stewart-2022`, `#event-bender-koller-2020`
и `#event-bender-2021` больше нет — если где-то стоит внешняя ссылка на них,
её надо поправить.

По дорожке критики после 2000 года получилось 10 событий, а не 8, как в таблице
второго документа: там не учтены Печеник и др. 2015 и Пильщиков 2018, добавленные
по сноскам первого документа.

## Локальный просмотр

TimelineJS забирает `data/timeline.json` через `fetch`, поэтому открыть
`index.html` как файл нельзя — нужен http-сервер:

```
python -m http.server 8000
```

и `http://localhost:8000/`.

## Публикация на GitHub Pages

Репозиторий публикуется как есть, сборка не нужна. Файл `.nojekyll` отключает
Jekyll, чтобы `Timeline.md` не превращался в страницу.

```
gh auth login
gh repo create Timeline-DH --public --source=. --remote=origin --push
gh api -X POST repos/:owner/Timeline-DH/pages -f build_type=legacy \
  -f 'source[branch]=main' -f 'source[path]=/'
```

Дальше достаточно `git push`: Pages пересобирает сайт сам.

## Что осталось сверить

Пометки «сверить» стоят прямо в карточках (жёлтый блок). Коротко:

* **Морозов 1915** — страницы 93–134 по одному источнику, полное русское
  заглавие нужно сверить по выпуску «Известий ОРЯС».
* **Рейтблат 2018** — выходные данные подтверждены, содержание известно
  по названию и пересказам.
* **Менденхолл 1887** — страницы 237–249 против 237–246 в других источниках.
* **Моретти 2000** — конечная страница (68).
* **Книги без DOI** — Рэмзи 2011, Джокерс 2013, Гриммер, Робертс, Стюарт 2022,
  Берельсон 1952, Берроуз 1987.
* **По памяти** — LSA (страницы), word2vec и BERTopic (номера arXiv),
  GPT-3 (страницы), DOI статьи Печеника 2015.
* **Ярхо 1925** — номер журнала и страницы 45–60 по одному источнику,
  выходные данные окончания статьи 1927 года не найдены.
* **Сеземан 1918** — данные из библиографии в статье Ковалёва
  (Philologia Classica, 2024), заглавие там в английском переводе
  и восстановлено обратно; содержание известно по заглавию.
* **Кракауэр 1952** — DOI не найден; год в базах 1952 или 1953, номер зимний.
* **Олсен 1993** — DOI восстановлен по соседним статьям номера
  (с. 309–314 → BF01829380); стоит открыть ссылку и убедиться.
* **Фиш 1973** — упоминание разбора Милича по памяти; есть вторая часть
  статьи 1979 года в журнале boundary 2.
* **RuBERT** — цитируется препринт arXiv, не версия из сборника «Диалога-2019».
* **ruRoBERTa** — событие стоит на 2024 годе, то есть на дате статьи.
  Документ предлагает датировать его выпуском модели, но год выпуска
  подтвердить не удалось: поле `createdAt` в API Hugging Face для
  `ai-forever/ruRoberta-large` отдаёт служебную дату 2 марта 2022 года,
  одинаковую у всех старых моделей. Нужен анонс Сбера или карточка модели.

## Известные ограничения

* **Порядок дорожек** задаётся хронологией первого события, а не вручную.
* **Плотность после 2010 года.** Шкала линейная: 23 события приходятся
  на 2010-е. Стартовый масштаб (`initial_zoom: 3` — лента втрое шире окна)
  подобран так, чтобы 2010-е читались; вся шкала целиком видна после
  нескольких нажатий «минус» на ленте.
* **Эпохи** рисуются полосой под лентой и не привязаны к конкретной дорожке —
  они описывают смену методов, а не всех трёх линий сразу.
