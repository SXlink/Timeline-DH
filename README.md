# Таймлайн «Текст как данные»

Интерактивная шкала ключевых работ о тексте как данных — от подсчёта букв
у Маркова (1913) до языковых моделей в роли разметчиков (2023). Собрана
на [TimelineJS3](https://timeline.knightlab.com/) (Knight Lab), данные лежат
в одном JSON-файле, страница публикуется на GitHub Pages.

Исходные документы (`Timeline.md`, «Дополнения…», «Мои комментарии.txt»
и PDF статьи Маккарти) лежат рядом локально, но в репозиторий не входят:
они перечислены в `.gitignore`. Всё их содержание перенесено в карточки.
Всего 55 событий на трёх дорожках, ссылки по ГОСТ Р 7.0.5-2008.

| Дорожка | Главных | Дополнительных | До 2000 | После 2000 |
| --- | --- | --- | --- | --- |
| Методы | 20 | 3 | 10 | 13 |
| Теория и методология | 16 | 0 | 6 | 10 |
| Критика | 15 | 1 | 6 | 10 |

## Что внутри

| Файл | Зачем |
| --- | --- |
| `index.html` | страница: шапка, легенда «Как читать шкалу», контейнер шкалы |
| `data/timeline.json` | все данные: титульная карточка, 4 эпохи, 55 событий |
| `assets/timeline-init.js` | настройки TimelineJS (язык, масштаб, хеш-закладки) |
| `assets/custom.css` | оформление страницы, цвета эпох, типографика карточек |
| `assets/favicon.svg` | иконка вкладки |


Библиотека подключена с CDN Knight Lab и **закреплена на версии 3.9.12**
(в `index.html` два адреса: CSS и JS). Версия `latest` на момент сборки была
побайтово той же; закрепление нужно, чтобы вёрстка не поехала после обновления
библиотеки.

## Как устроены данные

### Дорожки

Поле `group` у события: `Методы`, `Теория и методология`, `Критика`. TimelineJS
рисует каждую группу отдельным рядом на ленте. Традиция (гуманитарная,
социально-научная, общая) в группу не вынесена — она стоит первой строкой
внутри карточки, в `<p class='tl-line'>`.

Порядок рядов задать нельзя: библиотека сортирует события по дате и нумерует
группы по первому появлению. Поэтому ряды идут **Методы (1887) → Критика (1916)
→ Теория и методология (1925)**, а не «методы — теория — критика».

### Эпохи

Четыре записи в `eras`, у каждой обязательны `start_date` и `end_date`.
Цвета заданы в `assets/custom.css` переменными `--era-1 … --era-4`.

Важно: TimelineJS раздаёт эпохам классы по кругу `color1 → color2 → … → color5
→ color0`, то есть **первая эпоха получает `tl-timeera-color1`**, а не `color0`.
Номера переменных в CSS подогнаны под это, и те же цвета стоят у кружков
в легенде — при добавлении эпохи проверьте, что оба места сходятся.

### Версии файлов и кеш

`index.html` подключает `assets/custom.css?v=…` и `assets/timeline-init.js?v=…`,
а сам скрипт запрашивает `data/timeline.json?v=…` (константа `DATA_VERSION`).
Без этого браузер и CDN GitHub Pages отдают старые файлы, и после правки
читатель видит прежнюю шкалу. **Меняйте дату в обоих местах при каждом
обновлении данных или оформления.**

### Полосы дорожек

TimelineJS задаёт полосам групп одинаковую высоту (156,5 px при шаге 145 px),
то есть соседние полосы заходят друг на друга примерно на 11 пикселей. С родной
серой заливкой это читалось так, будто «Критика» захватывает часть «Методов».
В `custom.css` заливка снята, дорожки разделены волосяной линией — нахлёст
перестал быть виден. Подпись дорожки осталась там, где её ставит библиотека:
у верхнего края полосы она налезает на первый ряд маркеров.

### Адреса карточек и пары «метод — критика»

Стрелок между карточками TimelineJS не рисует. Вместо них — ссылки внутри
описаний. Работает это так:

1. У каждого события есть `unique_id`, в опциях включён `hash_bookmark: true`.
   Адрес карточки — `#event-<unique_id>`, например
   `.../#event-markov-1916`. Этим адресом можно делиться.
2. Библиотека слушает `hashchange`, поэтому обычная ссылка
   `<a href='#event-markov-1916'>` переводит шкалу на нужную карточку.
3. **`target='_self'` обязателен.** TimelineJS прогоняет HTML карточек через
   DOMPurify и вешает `target="_blank"` на каждую ссылку, у которой атрибута
   `target` нет. Без `_self` переход по паре открывает новую вкладку.
   Внешние ссылки (DOI, URL) оставлены с `target='_blank'` намеренно.

`unique_id` должен состоять из латиницы, цифр и дефисов и начинаться с буквы:
библиотека пропускает идентификаторы через slugify, который вырезает кириллицу
и подставляет `_` перед начальной цифрой. Схема здесь — `фамилия-год`
(`markov-1916`, `mccarty-2003`).

### Соразмерность событий

Размер маркера TimelineJS не различает, поэтому масштаб передан текстом:

* **главные работы** (51 штука) — абзац описания, ссылка по ГОСТ, блок переходов;
  у четырёх ранних карточек вдобавок фотография;
* **дополнительные события** (4 штуки — `stylo`, RuBERT, ruRoBERTa, Пильщиков) —
  одна строка в `<p class='tl-minor'>` и ссылка, без картинки.

Классы абзацев внутри карточек:

| Класс | Что это |
| --- | --- |
| `tl-lede` | лид титульной карточки |
| `tl-line` | подзаголовок-«линия»: гуманитарная, социально-научная, русская ветка |
| `tl-ref` | ссылка по ГОСТ |
| `tl-link` | блок переходов к парным карточкам |
| `tl-minor` | одна строка у дополнительного события |

Класс `tl-verify` (жёлтый блок «что осталось сверить») остался в `custom.css`,
но в данных больше не встречается: все пометки сняты после сверки.

У всех событий стоит `"autolink": false`: ссылки расставлены руками, а автолинковщик
библиотеки оборачивает в `<a>` в том числе и видимый текст URL, ломая разметку.

### Картинки

Поля `media.url`, `media.caption`, `media.credit`. Сейчас картинки есть
у четырёх карточек: Марков, Морозов, Лассуэлл — файлы с Wikimedia Commons,
лицензия указана в `credit`.

Четвёртая, **Ярхо**, — особый случай: это несвободный файл с `ru.wikipedia.org`,
загруженный туда по обоснованию добросовестного использования для статьи
о Ярхо. Такое обоснование не распространяется на сторонний сайт, и картинка
берётся горячей ссылкой с `upload.wikimedia.org`. Если таймлайн публикуется
всерьёз, фотографию стоит заменить на свободную или получить разрешение
у владельца оригинала (`bibliophily-spb.ru`).

Чтобы добавить картинку, достаточно дописать блок `media` в событие;
на дополнительных событиях картинок нет сознательно.

### Что объединено и перенесено

Второй документ предлагал три перестановки, чтобы разгрузить 2010-е; они сделаны:

* **Джокерс 2013** сперва был переведён в формат дополнительного события,
  но после правок получил полную карточку; макроанализ по-прежнему упомянут
  фразой и в карточке Моретти.
* **Гриммер, Робертс, Стюарт 2022** больше не отдельное событие: книга описана
  абзацем и второй ссылкой в карточке их же статьи 2013 года.
* **Бендер и Коллер 2020** и **Бендер и др. 2021** слиты в одно событие
  `bender-2020-2021` с `end_date`, то есть маркером-отрезком на ленте.

Старых адресов `#event-grimmer-roberts-stewart-2022`, `#event-bender-koller-2020`
и `#event-bender-2021` больше нет — если где-то стоит внешняя ссылка на них,
её надо поправить.

По дорожке критики после 2000 года получилось 10 событий, а не 8, как в таблице
второго документа: там не учтены Печеник и др. 2015 и Пильщиков 2018, добавленные
по сноскам первого документа.

## Локальный просмотр

TimelineJS забирает `data/timeline.json` через `fetch`, поэтому открыть
`index.html` как файл нельзя — нужен http-сервер:

```
python -m http.server 8000
```

и `http://localhost:8000/`.

## Публикация на GitHub Pages

Репозиторий публикуется как есть, сборка не нужна. Файл `.nojekyll` отключает
Jekyll, чтобы `Timeline.md` не превращался в страницу.

```
gh auth login
gh repo create Timeline-DH --public --source=. --remote=origin --push
gh api -X POST repos/:owner/Timeline-DH/pages -f build_type=legacy \
  -f 'source[branch]=main' -f 'source[path]=/'
```

Дальше достаточно `git push`: Pages пересобирает сайт сам.

## Сверка источников

Пометки «сверить» сняты: выходные данные проверены по источникам, блоки
`tl-verify` из данных удалены. Что подтвердилось по ходу работы:

* **Морозов 1915** — страницы 93–134 и полное заглавие подтверждены сноской
  в публикации архивного фрагмента (ссылка стоит в самой карточке) и записью
  РГБ об отдельном оттиске 1916 года (42 с., 14 диагр.).
* **Марков 1916** — та же сноска подтверждает «Известия имп. Академии наук.
  1916. Сер. 6. Т. 10. № 4. С. 239–242»; текст выложен на `textology.ru`.
* **Менденхолл** — проверка метода на шекспировском вопросе вынесена
  во вторую ссылку карточки: Popular Science Monthly, 1901, т. 60, с. 97–105.
* **Маккарти 2003** — в самой статье напечатан DOI `10.1081/E-ELIS 120008491`,
  но через `doi.org` он не разрешается, поэтому в карточке DOI не указан.

## Известные ограничения

* **Порядок дорожек** задаётся хронологией первого события, а не вручную.
* **Плотность после 2010 года.** Шкала линейная: 23 события приходятся
  на 2010-е. Стартовый масштаб (`initial_zoom: 3` — лента втрое шире окна)
  подобран так, чтобы 2010-е читались; вся шкала целиком видна после
  нескольких нажатий «минус» на ленте.
* **Эпохи** рисуются полосой под лентой и не привязаны к конкретной дорожке —
  они описывают смену методов, а не всех трёх линий сразу.
